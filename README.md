# Activitat-2-Projecte-4
# Tasca 2: Git, viatjant pel temps

## Descripció de l'activitat

En aquesta activitat es treballa el control de versions amb Git i GitHub, aprenent a gestionar l'historial d'un repositori i a recuperar versions anteriors dels fitxers i del projecte. L'objectiu és conèixer com registrar els canvis mitjançant commits ben estructurats, consultar l'historial de modificacions i utilitzar diferents eines de Git per controlar l'evolució d'un projecte.

Durant la pràctica es crea un repositori a GitHub anomenat `projecte4-tasca02` i es documenten els exercicis en un fitxer Markdown. Es treballa amb les comandes `git log`, `git show`, `git status`, `git restore`, `git revert` i `git reset`, comparant-ne també el funcionament amb les eines gràfiques de Visual Studio Code i Git Graph.

Finalment, es realitzen diferents modificacions en un fitxer de configuració de xarxa per simular errors, recuperar estats anteriors i comprovar com evolucionen els commits al llarg del projecte.

Aquesta activitat permet entendre la importància del control de versions, millorar l'organització del treball i aprendre a gestionar els canvis d'un repositori de manera ordenada i professional.
